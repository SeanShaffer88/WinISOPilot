# WinISOPilot

**Short:** Guided Windows 10/11 ISO customizer: remove apps, change defaults, slim the image, and build a new ISO, with every option explained. Also downloads Windows from Microsoft and writes bootable USB sticks.

**Long:** WinISOPilot helps anyone build a cleaner Windows 10 or 11 installer. Choose an official ISO and an edition, and WinISOPilot reads what's actually inside it. Then pick from more than 100 options: built-in apps, optional features, background services, privacy and desktop defaults, Windows Setup checks, and slimming. Every option says in plain language what it does, how risky it is, what could stop working, and how to undo it. Beginners get a guided, one-section-at-a-time layout that hides risky choices. Experts get a dense table with package IDs and every uncatalogued item in the image. Add signed drivers (for example Intel RST/VMD storage drivers so Setup can see the disk). Nothing changes until you review and build, and your original ISO is never modified. WinISOPilot can also download official Windows media straight from Microsoft (hash-verified) and write any Windows ISO to a bootable USB stick (MBR or GPT, FAT32 or NTFS, optional DATA partition, read-back verify).

**Keywords:** Windows 11, Windows 10, ISO, debloat, customize, DISM, unattended, slim, installation media, offline servicing, driver injection, bootable USB, Rufus alternative

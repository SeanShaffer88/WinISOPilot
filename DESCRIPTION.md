# WinISOPilot

**Short:** Guided Windows 10/11 ISO customizer: remove apps, change defaults, slim the image, and build a new ISO, with every option explained.

**Long:** WinISOPilot helps anyone build a cleaner Windows 10 or 11 installer. Choose an official ISO and an edition, and WinISOPilot reads what's actually inside it. Then pick from more than 100 options: built-in apps, optional features, background services, privacy and desktop defaults, Windows Setup checks, and slimming. Every option says in plain language what it does, how risky it is, what could stop working, and how to undo it. Beginners get a guided, one-section-at-a-time layout that hides risky choices. Experts get a dense table with package IDs and every uncatalogued item in the image. Nothing changes until you review and build, and your original ISO is never modified.

**Keywords:** Windows 11, Windows 10, ISO, debloat, customize, DISM, unattended, slim, installation media, offline servicing

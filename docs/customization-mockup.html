5. Review and create a copy

Your original Windows file stays untouched.

Available now: create a new ISO with a Windows Setup edition preference. All editions stay inside. Apps, drivers, updates and slimming are not applied.

This uses the Retail setup channel. It does not provide a license or activation. Existing setup configuration blocks this option.

During work: copy → write edition preference → create ISO → read back and check → save new ISO.

Cancel waits for active native work. Then: Keep files (default), or delete only confirmed unchanged files from this run.

Boot and Windows installation: not tested.

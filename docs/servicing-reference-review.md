# Servicing reference review — first implementation slice

These references inform UX and validation ideas. They are not runtime dependencies, removal prescriptions, or evidence that a customized image boots.

| Reference | What the review established | Adopted here |
|---|---|---|
| [MicrowinDebloatWin11](https://github.com/firespydr/MicrowinDebloatWin11) | README tutorial using WinUtil, rather than a separate reproducible servicing implementation. | Guided choices and explicit explanation of app removal; no third-party script execution or copied presets. |
| [WinUtil Windows 11 creator guide](https://winutil.christitus.com/guides/win11creator/) | Documents a wizard, persistent logs, app choices and ISO workflow. | Explicit per-app requests, persistent command/exit evidence, original preservation and retained edition inventory. Hardware bypasses, encryption changes, USB erasure and automatic tool installation are outside this slice. |
| [WindowsSimplify](https://github.com/WhatTheBlock/WindowsSimplify) and its [Windows 11 README](https://github.com/WhatTheBlock/WindowsSimplify/blob/master/11/README.md) | Archived July 24, 2024. Lists prebuilt ISO downloads, hashes and a Store restore-pack caveat; does not supply a verified current dependency/removal recipe. | Retained-function and recovery caveats. No ISO downloads, restore-pack execution, or adoption of unsupported compatibility claims. |
| [Windows-Debloated-ISOs](https://github.com/iamgeetarted/Windows-Debloated-ISOs) | Fork carries the same Windows 11 README/download material. It is not independent validation; an “official ISO” marketing claim was not verified. | Require our own inventory, source hash and per-operation evidence; no borrowed “safe” labels or claimed savings. |

The first slice deliberately uses Microsoft's documented [offline app-package operations](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/dism-app-package--appx-or-appxbundle--servicing-command-line-options?view=windows-11) and [component-store cleanup](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/reduce-the-size-of-the-component-store-in-an-offline-windows-image?view=windows-11), under a conservative [compatible DISM environment](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/dism-supported-platforms?view=windows-11) gate. Only the selected edition's private WIM copy is serviced. Original ISO and all other editions remain. No ResetBase, manual WinSxS deletion, general dependency resolver, or arbitrary package stripping is introduced.

Live successful servicing, boot, install, retained-app behavior, updates and recovery remain unverified. The current development environment is unelevated; the available build 26300 ISO is blocked with installed ADK 26100. Deterministic fault fixtures are process-boundary tests, not evidence of a real successful Windows image modification.
